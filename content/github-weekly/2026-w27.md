## 本周新星

本周新创建并获得大量关注的项目。

### 1. [ios-location-spoofer](https://github.com/mekos2772/ios-location-spoofer)

无需越狱就能在 iOS 上修改 GPS 定位的独立工具，通过 MITM 代理拦截并篡改 Apple 地图定位服务的响应数据。支持 Shadowrocket、Surge、Loon、Quantumult X 和 Stash 五个代理平台，即导即用，免编译免开发者账号。还额外实现了蜂窝基站坐标修改和运动状态伪造，让定位修改更加真实可信。

- {icon:lucide:star} 1.1k | {icon:lucide:code} JavaScript | {icon:lucide:git-fork} 155

### 2. [Fundamental-Ava](https://github.com/TianhangZhuzth/Fundamental-Ava)

一个构建自主数字人类智能体的开源框架，让大规模 AI Agent 群体在一个共享环境中运行，每个 Agent 都拥有独立的记忆、信念系统和社交模型。它关注的是群体层面涌现出的行为——分工、联盟、规范形成——这些没有被任何程序员直接编写，而是通过数千次局部交互自然产生的。适合研究多智能体协作和社会模拟的开发者。

- {icon:lucide:star} 754 | {icon:lucide:code} Python | {icon:lucide:git-fork} 78

### 3. [Awesome-Blender-Seedance-Workflow-Usecases](https://github.com/Evolink-AI/Awesome-Blender-Seedance-Workflow-Usecases)

EvoLink 整理的 Blender + Seedance AI 视频生成工作流合集，收录了 25 个来自真实创作者的案例。覆盖摄像机控制、Blender 预览布局、多角色场景编排、FBX/Mixamo 动作参考、ComfyUI 风格迁移等场景。每个案例都配有原始出处和创作者信息，适合 AI  filmmakers 快速上手将 3D 预览转化为 AI 视频。

- {icon:lucide:star} 289 | {icon:lucide:code} Python | {icon:lucide:git-fork} 24

### 4. [reverse-flow-skill](https://github.com/lingbol088-spec/reverse-flow-skill)

面向 AI Agent 的逆向工程流程技能，专为本地 CTF、crackme 和 wargame 环境设计。启动后按「分析 → 报告 → 逆向 → 深度逆向 → 漏洞研判 → 用户选择下一步」的标准流程推进，采用英文内核提示词 + 中文用户交互的双语策略。当用户表达不清晰时，技能会自动做意图恢复而不是直接终止，对逆向新手来说很友好。

- {icon:lucide:star} 277 | {icon:lucide:code} Python | {icon:lucide:git-fork} 160

## 本周飙升

已有一定基础、本周热度持续攀升的项目。

### 1. [elastic/elasticsearch](https://github.com/elastic/elasticsearch)

业界最流行的分布式搜索和分析引擎，基于 Lucene 构建，提供近实时的全文搜索、结构化搜索和分析能力。广泛应用于日志分析、应用搜索和可观测性场景，拥有庞大的插件生态系统和成熟的社区支持。

- {icon:lucide:star} 77.2k | {icon:lucide:code} Java | {icon:lucide:git-fork} 25.9k

---

### 2. [BerriAI/litellm](https://github.com/BerriAI/litellm)

一个轻量级的 LLM API 网关和代理服务器，用统一的 OpenAI 兼容接口调用 100+ 大模型提供商（包括 Bedrock、Azure、OpenAI、Anthropic、VertexAI 等）。内置成本追踪、数据护栏、负载均衡和日志记录功能，让团队无需为每个模型重新适配 API，是 LLM 应用开发的实用基础设施。

- {icon:lucide:star} 52.4k | {icon:lucide:code} Python | {icon:lucide:git-fork} 9.4k

### 3. [servo/servo](https://github.com/servo/servo)

Mozilla 发起、由社区接力的 Rust 原生浏览器引擎，专注于提供轻量级、高性能的 Web 渲染方案。本周仍在活跃开发，持续推进 Ed448 加密算法实现和组件化架构改进，适合嵌入式应用和希望将 Web 技术集成到原生应用的开发者。

- {icon:lucide:star} 37.3k | {icon:lucide:code} Rust | {icon:lucide:git-fork} 3.7k
