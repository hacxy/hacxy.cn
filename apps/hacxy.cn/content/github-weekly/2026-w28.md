## 本周新星

本周新创建并获得大量关注的项目。

### 1. [Shpigford/knockoff](https://github.com/Shpigford/knockoff)

一款 Chrome 浏览器扩展，帮助用户在 Amazon 购物时过滤掉仿冒品牌和山寨商品，只展示真正的、有口碑的品牌。解决了 Amazon 平台上充斥大量伪装成知名品牌的小作坊产品的问题，让用户在搜索结果中直接跳过这些伪品牌，提升购物体验。

- {icon:lucide:star} 1.6k | {icon:lucide:code} JavaScript | {icon:lucide:git-fork} 50

### 2. [withmarbleapp/os-taxonomy](https://github.com/withmarbleapp/os-taxonomy)

由 Marble 发布的开放结构化教育知识图谱，覆盖小学阶段 8 个学科、1,590 个微主题和 3,221 条先修关系。将课程标准分解为细粒度的可教学单元，构建为有向无环图（DAG），并标注了硬/软先修依赖。支持 NGSS、Common Core、英国国家课程等多种课程标准对齐，提供 JSON 数据格式，可直接加载用于教育产品开发。

- {icon:lucide:star} 1.4k | {icon:lucide:code} JavaScript | {icon:lucide:git-fork} 268

- {icon:lucide:star} 582 | {icon:lucide:code} Python | {icon:lucide:git-fork} 12

### 4. [Robbyant/lingbot-vision](https://github.com/Robbyant/lingbot-vision)

### 5. [Robbyant/lingbot-video](https://github.com/Robbyant/lingbot-video)
