# 深模块

源自《软件设计哲学》（A Philosophy of Software Design）：

**深模块** = 小接口 + 大量实现

```
┌─────────────────────┐
│   Small Interface   │  ← 少量方法，简单参数
├─────────────────────┤
│                     │
│                     │
│  Deep Implementation│  ← 隐藏的复杂逻辑
│                     │
│                     │
└─────────────────────┘
```

**浅模块** = 大接口 + 少量实现（应避免）

```
┌─────────────────────────────────┐
│       Large Interface           │  ← 大量方法，复杂参数
├─────────────────────────────────┤
│  Thin Implementation            │  ← 只是透传
└─────────────────────────────────┘
```

设计接口时问自己：

- 能不能减少方法数量？
- 能不能简化参数？
- 能不能把更多复杂度藏到内部？
