# RESOURCES.md 格式

`RESOURCES.md` 是此主题经过精选的可信来源集。讲解的知识应从这里获取，而不是从参数化猜测中获取。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练的科学与实践》—— Zatsiorsky & Kraemer](https://example.com)
  关于训练计划制定与适应的基础文本。用于：任何与周期化、恢复、强度区间有关的内容。
- [文章："我应该训练多少？"—— Greg Nuckols（Stronger By Science）](https://example.com)
  关于训练量基准的循证综述。用于：每个肌群的每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比的 subreddit，对"民科"严格管控。用于：训练计划评估、平台期排查。
- 本地：{健身房名称} 周二力量课
  用于：举重动作的实时教练反馈。
```

## 规则

- **只收高可信度。** 优先选择一手来源、公认专家、同行评审工作以及有强有力管理的社区。如果某个资源是伪装成教育的营销，就别收录。
- **为每条条目添加注释。** 三个月后，一个裸链接毫无用处。加一行：它涵盖了什么，何时使用它。
- **按知识 / 智慧分组。** 对应 [SKILL.md](./SKILL.md) 中的理念。一个资源只出现在一组中也没关系。
- **明确标出空白。** 如果使命需要的某个领域没有好的资源，写一个 `## 空白（Gaps）` 部分列出缺失的内容。这将推动未来的搜索。
- **毫不留情地修剪。** 被证明是错误的、肤浅的或偏离使命的资源应该被移除，而不是埋没起来。五个精悍的来源胜过三十个平庸的。
- **记录社区偏好。** 如果用户选择不加入社区，在这里记下来，这样未来的会话就不会继续提议它们。
