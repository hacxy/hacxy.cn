# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范语言。所有讲解、练习和学习记录都应遵循其术语。构建它本身就是学习的一部分：把一个概念压缩成紧凑的定义，是用户理解它的证据。

## 结构

```md
# {主题} 术语表

{一两句话描述这个术语表涵盖的主题。}

## 术语

**肌肉肥大（Hypertrophy）**：
由反复训练带来的机械张力和代谢压力驱动的肌肉增长。
_避免_：增肌、练大

**渐进式超负荷（Progressive overload）**：
通过负荷、训练量或强度，系统地增加对肌肉的需求。
_避免_：更用力、升级

**RPE（自感疲劳程度）**：
对一组训练感受的 1–10 分自评，10 表示力竭，8 表示还能再做两个。
_避免_：努力分数、强度评级
```

## 规则

- **只有当用户理解某个术语时才添加。** 术语表是浓缩知识的记录，不是用户用来学习的字典。如果用户刚刚接触一个概念，等到他们能正确使用它之后，才把它提升到这里。
- **要有主见。** 当同一概念存在多个词时，选最好的一个，并把其余列为需要避免的同义词。语言就是这样被压缩的。
- **定义要紧凑。** 一两句话。定义术语"是什么"，而不是它做什么或怎么做。
- **在定义内部使用术语表自己的术语。** 一旦某个术语进入术语表，在任何地方都优先使用它——包括在其他定义内部。这就是让复杂术语日后更容易理解的原因。
- **出现自然聚类时分组到子标题下**（例如 `## 解剖学`、`## 编程`）。当术语相互连贯时，扁平列表也可以。
- **明确标记歧义。** 如果某个术语在更广泛的领域中用法松散，注明解决方案："在本工作区中，'set' 始终指正式组——热身组单独跟踪。"
- **随着理解的加深而修订。** 用户第一周写的定义到第六周可能就错了。就地更新；不要留下过时的条目。
