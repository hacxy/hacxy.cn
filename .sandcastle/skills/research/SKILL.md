name: research
description: 针对高可信度的一手来源调查一个问题，并把调查结果保存为仓库里的 Markdown 文件。当用户想要研究某个主题、收集文档或 API 事实，或想把阅读类跑腿工作交给后台 agent 时使用。
---

启动一个**后台 agent** 来做研究，这样它阅读的同时你可以继续干活。

它的任务：

1. 针对**一手来源**（primary sources）调查问题——官方文档、源代码、规范、第一方 API——而不是针对它们的二手转述。把每个论断都追溯回拥有它的那个来源。
2. 把调查结果写进一个 Markdown 文件，为每个论断标注来源。
3. 保存到仓库里已经存放此类笔记的位置；遵循现有惯例，如果没有惯例，就放在一个合理的位置并说明放在哪里。
